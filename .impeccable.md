## Design Context

### Users
Builders and hackathon judges evaluating an agentic cash-out demo (Runtime · Bankr × Propaganda). They use it in short, focused sessions to grant/revoke agent authority, run a cash-out plan, and inspect selective disclosure + payment evidence.

### Brand Personality
Fast, precise, technical — command-palette-native productivity, slightly cinematic rather than corporate.

### Aesthetic Direction
Raycast visual system (dark canvas `#07080a`, red action `#ff6363`, Inter + Instrument Serif hero, JetBrains Mono for code/evidence). Dense utility panels with glossy inset borders; red used sparingly as accent/link; light primary CTA on dark. Anti-references: mint crypto glow, purple SaaS gradients, flat card grids, beige/light-mode marketing.

### Design Principles
1. Dark canvas first — layer few brighter surfaces; depth via inset highlights, not heavy shadows.
2. Product-native evidence — command rows, hotkeys, status pills, monospace tool names.
3. Compact type (12–16px UI); oversized serif only for the Proofport brand moment.
4. Red is accent, never a surface wash; primary conversion uses light fill on dark.
5. 8px rhythm; panels dense, page spacing open.
