## Design Context

### Users
Builders and hackathon judges evaluating an agentic cash-out demo (Runtime · Bankr × Propaganda). They use it in short, focused sessions to grant/revoke agent authority, run a cash-out plan, and inspect selective disclosure + payment evidence.

### Brand Personality
Monumental, restrained, high-voltage — black-cathedral agency energy; type as architecture; one crimson signal.

### Aesthetic Direction
ThoughtLab visual system (void `#000000`, ash body `#cccccc`, frost display `#ffffff`, graphite meta `#4c4c4c`, crimson signal `#fc1c46` only on the primary pill + logo mark). Sole typeface Space Grotesk (Sui substitute). Transparent modules, hairline inputs, pill CTAs, no shadows/glows/card fills. Hierarchy via extreme scale jumps and whitespace. Anti-references: Raycast glass panels, mint crypto glow, purple SaaS gradients, multi-accent palettes, elevated cards.

### Design Principles
1. Subtraction first — five colors, one family, one rounded shape (the pill).
2. Crimson Signal appears once per view as the primary action (plus logo mark).
3. Display type is architectural (uppercase, weight 700, tight leading ≤ 0.96).
4. Cards are transparent content frames — no fills, borders, or elevation.
5. Body in ash (`#cccccc`), not pure white; meta in graphite.
