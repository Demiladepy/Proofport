## Design Context

### Users
Builders and hackathon judges evaluating Proofport’s agentic credit/reputation demo (Runtime · Bankr × Propaganda). Short sessions: grant/revoke, run cash-out, inspect selective disclosure + settlement evidence.

### Brand Personality
Warm, storybook, approachable crypto utility — parchment-and-marker, not terminal-black.

### Aesthetic Direction
Family visual system: cream canvas `#fbfaf9`, stone surfaces, inset hairline borders (no heavy shadows), Inter for UI/body, Barlow Condensed 500 as Family/Druk/GT America Compressed display substitute. Color is semantic punctuation (blue/orange/green/gold/red) against near-monochrome chrome. Primary CTA = ink black `#121212` pill. Ember orange `#ff3e00` for inline demo/accent links only. Hand-drawn-style SVG mascot/confetti clusters flank the hero.

### Design Principles
1. Cream parchment canvas on every full-bleed surface.
2. Cards defined by `inset 0 0 0 1px #f2f0ed`, not drop shadows.
3. Display headings use condensed Family substitute; never Inter at display size.
4. One dark filled CTA; sand pill for secondary; ember orange for text links.
5. Illustrations carry emotional weight; UI chrome stays quiet.
